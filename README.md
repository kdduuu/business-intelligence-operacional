
# Business Intelligence Operacional

*Projetos empresariais · Engenharia e análise de dados*

Coletânea de soluções de Business Intelligence desenvolvidas para extração, transformação, validação e análise de dados operacionais.

## Contexto empresarial

Os projetos deste repositório foram desenvolvidos durante minha atuação profissional como Analista de Dados em uma empresa do setor de logística.

As soluções atendem demandas reais de processamento, consolidação e análise de informações operacionais, transformando dados de diferentes fontes em relatórios estruturados para conferência e tomada de decisão.

## Projetos

| Projeto | Descrição |
| --- | --- |
| [Relatório de KM Excedente](./km-excedente/) | Consolidação, validação e apuração de quilometragem excedente. |
| [Relatório de Viabilidade por Condutor](./viabilidade-por-condutor/) | Integração de quilometragem, jornada, peso transportado e despesas operacionais. |


## Tecnologias utilizadas

- Power BI Desktop
- Power Query (linguagem M)
- DAX
- Microsoft Excel
- Extração de dados de documentos PDF

## Competências aplicadas

- Processos de ETL.
- Integração de múltiplas fontes de dados.
- Modelagem de dados.
- Qualidade e validação de informações.
- Implementação de regras de negócio.
- Rastreabilidade de registros.
- Desenvolvimento de indicadores operacionais.
- Business Intelligence aplicado ao ambiente empresarial.

## Confidencialidade

Este repositório possui finalidade demonstrativa e de portfólio profissional.

Os arquivos demonstrativos utilizam dados fictícios, sem disponibilizar as bases corporativas originais.
